# プロフィール画像の配置

このディレクトリへ、各自のローカル環境で以下の画像を配置してください。

- `human1.png`
- `human2.png`
- `human3.png`
- `human4.png`
- `human5.png`
- `human6.png`

開発用シードの`profile_url`は、`/assets/profiles/human1.png`〜`/assets/profiles/human6.png`を参照します。

インターン運営から提供された画像はローカル環境内でのみ使用し、Gitへcommitしないでください。このディレクトリの`.gitignore`でPNGファイルをGit管理から除外しています。
